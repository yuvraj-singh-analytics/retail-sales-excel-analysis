# 📊 Retail Sales & Operations Advanced Excel Analysis

## 🚀 Project Overview
This repository contains an end-to-end retail data analysis and financial model built in Microsoft Excel. The project analyzes nearly **10,000 transaction records** from a global superstore dataset to evaluate sales performance, product profitability, regional efficiency, and logistics optimization.

---

## 🛠️ Tools & Advanced Features Used
* **Spreadsheet Software:** Microsoft Excel
* **Data Cleansing & Transformation:** Power Query, conditional formatting, and custom calculated columns.
* **Advanced Formulas:** `XLOOKUP`, `SUMIFS`, nested logical statements (`IF`), and data validation.
* **Data Modeling & Summarization:** Dynamic Pivot Tables, Slicers, and calculated fields.
* **Executive Reporting:** Executive KPI Dashboards and visual distribution charts.

---

## 📈 Key Business Questions & Analytical Insights

1. **Customer Behavior & Shipping Preferences:**
   * Analyzed distribution across delivery modes (**Standard Class, Second Class, First Class**). Standard Class accounted for the highest volume of fulfillment.
   * Identified top-tier customers by order frequency and total revenue to support loyalty program targeting.

2. **Product Category Profitability:**
   * Evaluated performance across major categories (**Technology, Office Supplies, and Furniture**). 
   * Discovered that while *Technology* generated massive revenue, certain sub-categories in *Furniture* suffered from heavy discounting and negative profit margins.

3. **Logistics & Operational Efficiency:**
   * Analyzed state-level shipping costs and return logs to highlight fulfillment bottlenecks across high-volume regions like California, New York, and Texas.

## 📊 Dashboard Structure
The workbook is organized into structured sheets for maximum transparency:
* **`Orders` / `Returns` / `People`:** Raw data layers containing cleaned transaction records, return logs, and regional ownership maps.
* **`Pivot Tables`:** Structured aggregations tracking sales by segment, region, and customer.
* **`KPIS Dashboard` & `Sales Dashboard`:** Interactive executive summaries featuring core revenue metrics, cost of goods sold (COGS), and regional leaderboards (managed by regional teams: Anna Andreadi, Chuck Magee, Kelly Williams, and Cassandra Brandow).
